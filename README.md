# 축구 전술판

선수를 드래그해서 포메이션을 짜고, 링크나 이미지로 팀원에게 공유하는 웹 전술판입니다.
회원가입이나 서버 없이 브라우저만 있으면 PC·모바일 어디서든 쓸 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 인원 선택 | **11:11 축구**와 **5:5 · 6:6 · 7:7 풋살**을 지원하며, 인원에 맞는 실제 규격 경기장이 그려집니다 |
| 포메이션 | 11:11은 8종(4-3-3, 4-4-2, 4-2-3-1 등), 풋살은 인원별 5종씩 제공 |
| 선수 배치 | 유니폼을 드래그해서 원하는 위치로 자유롭게 이동 (터치 지원) |
| 꾸미기 | 필드 선수·골키퍼 유니폼 색상, 선수 이름(최대 12자) 변경 |
| 내 프리셋 | 포메이션을 최대 10개까지 이름 붙여 저장하고 골라 쓰기 |
| 자동 저장 | 모든 변경이 브라우저에 바로 저장되고, 다시 열면 마지막 프리셋이 그대로 나옴 |
| 링크 공유 | 현재 포메이션이 담긴 링크를 복사해서 공유 |
| 이미지 저장 | 경기장 화면을 PNG 이미지로 다운로드 |

## 사용법

### 1. 포메이션 만들기

1. 오른쪽 패널의 **인원**에서 경기 방식을 고릅니다. (`11:11`은 축구장, `5:5`·`6:6`·`7:7`은 풋살장)
2. **포메이션**에서 기본 배치를 고르면 선수들이 그 위치로 정렬됩니다.
3. 경기장의 유니폼을 **드래그**해서 위치를 세밀하게 조정합니다.
4. **필드 유니폼 / 골키퍼 유니폼**에서 색상을, **선수 이름**에서 이름을 바꿉니다. (1번이 골키퍼)

> 💡 포메이션을 바꾸면 선수 위치는 새 포메이션 기본값으로 바뀌지만, 입력한 이름은 그대로 남습니다.

### 2. 내 프리셋으로 여러 개 저장하기

여러 전술(예: 공격형, 수비형)을 따로 저장해두고 바꿔가며 쓸 수 있습니다.

- **새로 만들기**: 프리셋 목록에서 `+ 프리셋 추가`를 고릅니다. (최대 10개)
- **전환하기**: 프리셋 목록에서 원하는 프리셋을 고릅니다.
- **이름 바꾸기**: **프리셋 이름** 칸에 입력하면 바로 반영됩니다.
- **삭제하기**: **삭제** 버튼을 누릅니다. 첫 번째 프리셋은 삭제할 수 없습니다.
- **초기화**: 현재 프리셋의 포메이션·선수 위치·이름·유니폼 색을 기본값으로 되돌립니다. (프리셋 이름과 인원은 유지)

> 💡 따로 저장 버튼은 없습니다. 바꾸는 즉시 자동 저장됩니다.
> 단, 데이터는 **지금 쓰는 브라우저에만** 저장되므로 다른 기기나 브라우저에서는 보이지 않습니다. 옮기고 싶다면 링크 공유를 이용하세요.

### 3. 공유하기

- **링크 복사**: 현재 포메이션이 담긴 링크가 클립보드에 복사됩니다. 메신저 등에 붙여넣어 보내면 됩니다.
- **이미지 저장**: 경기장 화면이 PNG 파일로 다운로드됩니다.

### 4. 공유받은 링크 열기

링크를 열면 공유받은 포메이션이 **보기 전용**으로 표시됩니다. 내 프리셋은 바뀌지 않습니다.

- **내 프리셋으로 저장**: 내 프리셋에 추가되어 자유롭게 수정·재공유할 수 있습니다. (프리셋이 10개 꽉 찼다면 하나를 지운 뒤 저장)
- **내 프리셋으로 돌아가기**: 공유 화면을 닫고 원래 쓰던 프리셋으로 돌아갑니다.

## 개발

Node.js 18 이상이 필요합니다.

```sh
npm install
npm run dev      # watch 모드: http://localhost:8000 이 열리고, 파일 저장 시 자동 반영
npm run build    # 타입 체크(tsc) 후 dist/ 에 빌드
npm run preview  # 빌드 결과(dist/) 확인
```

## 구조

MVC 패턴으로 나뉘어 있습니다.

```
src/
├─ main.ts                    진입점: Model·View·Controller 생성과 연결
├─ const/                     변하지 않는 값 모음 (모두 대문자 이름)
│  ├─ BoardCONST.ts           선수 수, 기본 포메이션·색상·이름
│  ├─ FormationCONST.ts       포메이션 종류, 줄 배치 위치
│  ├─ PresetCONST.ts          내 프리셋 최대 개수, 기본 이름
│  ├─ PitchCONST.ts           축구·풋살 경기장 규격(m), 잔디 색
│  ├─ LayoutCONST.ts          미터당 픽셀, 캔버스 여백
│  ├─ PlayerCONST.ts          선수 터치·드래그 영역 크기
│  ├─ StorageCONST.ts         localStorage 키, 좌표 정밀도
│  └─ UICONST.ts              안내 문구, 입력 제한, 토스트 시간
├─ model/                     데이터와 규칙 (화면을 모름)
│  ├─ types.ts                상태 타입
│  ├─ formations.ts           포메이션 위치 계산
│  ├─ BoardStorage.ts         프리셋 저장(슬롯별 키), 공유 링크 인코딩
│  └─ BoardModel.ts           프리셋 관리, 공유 보기, 보드 편집
├─ view/                      화면 (Model을 직접 바꾸지 않음)
│  ├─ pitchLayout.ts          경기장 종류별 캔버스 크기 계산
│  ├─ PitchView.ts            경기장
│  ├─ PlayerView.ts           선수 유니폼
│  ├─ BoardView.ts            Pixi 캔버스, 드래그, 이미지 저장
│  └─ PanelView.ts            오른쪽 설정 패널
├─ controller/
│  └─ BoardController.ts      View 이벤트 → Model 변경 → View 갱신
└─ style.css
```
